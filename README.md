> Repositório contendo todos os códigos, exercícios e projetos desenvolvidos durante o curso **Maratona Java - Virado no Jiraya** do canal DevDojo Academy.

## 📋 Sobre o Curso

Este é um dos cursos de Java mais completos disponíveis gratuitamente em português, criado pelo professor William Suane do canal DevDojo. O curso aborda desde os fundamentos básicos da linguagem até conceitos avançados de programação.

**Duração:** +200 aulas (aproximadamente 26 horas)  
**Nível:** Iniciante a Avançado  
**Idioma:** Português (BR)

## 🎯 Objetivo

Dominar a linguagem Java através de uma abordagem prática e completa, construindo uma base sólida para desenvolvimento de aplicações robustas e preparação para o mercado de trabalho.

## ⚙️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/DiegoLimaInCode/CursoDevDojo_Java.git
cd CursoDevDojo_Java
```

### 2. Abra o projeto na sua IDE

- **IntelliJ IDEA:** File → Open → Selecione a pasta do projeto
- **Eclipse:** File → Import → Existing Projects into Workspace

### 3. Execute as classes

Navegue até a pasta `src` e execute as classes principais de cada módulo.
