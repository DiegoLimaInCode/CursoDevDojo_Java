🚀 [Curso DevDojo Java]

✨ Descrição
Este repositório contém todos os projetos e exercícios desenvolvidos durante o **Curso de Java - Virado no Jiraya** do DevDojo. O curso aborda desde os fundamentos da linguagem Java até conceitos avançados, incluindo Programação Orientada a Objetos, coleções, exceções, I/O, JDBC, testes unitários e muito mais.

**Objetivo**: Dominar a linguagem Java através de uma abordagem prática e completa, construindo uma base sólida para desenvolvimento de aplicações robustas.

🛠️ Tecnologias Utilizadas
* **Linguagem**: Java 17+ (LTS)
* **Build Tool**: Maven
* **Banco de Dados**: MySQL (para módulos de JDBC)
* **Testes**: JUnit 5
* **IDE Recomendada**: IntelliJ IDEA ou Eclipse
* **Controle de Versão**: Git

📦 Pré-requisitos
O que é necessário ter instalado na máquina antes de começar:

* **JDK (Java Development Kit)** - Versão 17 ou superior
* **Maven** (gerenciador de dependências)
* **Git** (para clonar o repositório)
* **IntelliJ IDEA** ou **Eclipse** (IDE)
* **MySQL** (opcional, para exercícios de JDBC)

⚙️ Instalação
Passos para configurar e executar o projeto localmente:

1. **Clonar o Repositório**
```bash
git clone https://github.com/DiegoLimainCode/CursoDevDojo_Java.git
cd CursoDevDojo_Java
```

2. **Importar o Projeto na IDE**
   - Abra sua IDE (IntelliJ IDEA ou Eclipse)
   - Importe o projeto como um projeto Maven
   - Aguarde o download das dependências

3. **Executar os Exemplos**
   - Navegue até a pasta `src`
   - Execute as classes principais de cada módulo

📚 Conteúdo do Curso
O curso aborda os seguintes tópicos:

- **Introdução ao Java**: Tipos primitivos, operadores, estruturas condicionais
- **Orientação a Objetos**: Classes, objetos, herança, polimorfismo, encapsulamento
- **Collections**: List, Set, Map e suas implementações
- **Exceções**: Try-catch, throws, custom exceptions
- **Classes Utilitárias**: String, Date, Calendar, Formatação
- **Generics**: Criação e uso de tipos genéricos
- **Inner Classes**: Classes aninhadas e anônimas
- **JDBC**: Conexão com banco de dados
- **Testes Unitários**: JUnit para garantir qualidade do código
- **Lambdas e Streams**: Programação funcional em Java
- **Threads**: Programação concorrente
- **E muito mais!**
